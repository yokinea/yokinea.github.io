OWASP Top10 ｜SSRF 漏洞深度复盘

一、漏洞概述

SSRF 即服务器端请求伪造

攻击者利用服务器作为代理，发起任意网络请求，对内网资产、本地服务、外部接口进行探测与攻击。

主要危害：

内网端口扫描、读取本地文件、攻击内网应用、调用恶意接口、探测云服务器元数据信息。

二、漏洞核心原理

  1. 服务端代码主动请求外部可控 URL，未做地址与协议严格过滤
  2. 攻击者传入恶意地址，由服务器代为发起访问
  3. 服务器权限远大于客户端，可访问内网隔离资源

常见支持危险协议

  • http/https：探测内外网站点、端口
  • file：读取服务器本地任意文件
  • dict：探测内网端口服务
  • gopher：发送自定义数据包，配合漏洞组合利用

三、本地环境搭建

  1. 启动 Pikachu 漏洞靶场，保证网络环境正常
  2. 进入功能模块：SSRF
  3. 确认页面存在远程图片加载、网址预览类可控请求点
  4. 关闭本地简易防火墙，保证内网互通测试正常

四、Pikachu 靶场完整复现

1. 基础 SSRF 内网探测

  1. 进入 Pikachu SSRF 关卡

  2. 输入内网存活主机地址，由服务器代为访问

  3. 批量遍历网段，实现内网存活主机扫描，依次输入对网站进行遍历

也可使用脚本遍历

3. Dict 协议端口探测

使用 dict 协议对内网主机进行端口扫描，快速判断端口开放状态。

五、实战踩坑点

  1. 部分环境禁用非 http 协议，file、dict 无法使用
  2. 云服务器严格限制内网访问，探测范围受限
  3. 请求超时时间过短，端口扫描准确率低
  4. 存在 DNS 重绑定防护，域名绕过容易失效
  5. 服务端开启代理，无法精准探测真实内网

六、防御方案

  1. 禁用所有非 HTTP/HTTPS 危险协议
  2. 拦截内网 IP、本地回环地址、网段地址
  3. 设置 URL 访问白名单，仅允许可信外部域名
  4. 限制请求端口，仅开放 80、443 常用端口
  5. 关闭服务器 DNS 重绑定解析
  6. 统一请求超时时间，防止长时间扫描探测
  7. 部署 WAF 拦截 SSRF 特征请求
