flag4

用sudo查看授权的命令，有一个git命令不需要密码

执行sudo git -p help，

当git -p help命令执行完，如果内容再页面上显示不完，就会进入交互状态，此时可以输入!/bin/bash，以root身份进入bash（因为加了sudo），调整字体大小或显示框大小都可以
