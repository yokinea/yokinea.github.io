TCP/IP 四层模型与常见协议

一、原理

TCP/IP 四层模型是互联网核心的网络分层架构，是网络数据传输的基础框架，相比 OSI 七层模型更简化、更贴合实际网络应用，各层分工明确，实现数据从源设备到目标设备的封装与解封装，保障网络通信有序进行。

  • 应用层：直接为应用程序提供服务，负责数据交互逻辑，是用户与网络交互的接口，所有网络应用的通信规则都在这一层定义。
  • 传输层：负责端到端的数据传输控制，建立主机间的数据传输通道，保障数据传输的可靠性或高效性。
  • 网络层：负责数据的路由选择，确定数据传输的最佳路径，实现不同网络之间的数据转发。
  • 网络接口层：负责数据帧的封装、传输与接收，对接物理硬件，实现数据在物理链路中的传输。

各层核心常见协议：

  • 应用层：HTTP/HTTPS（网页访问）、DNS（域名解析）、FTP（文件传输）、Telnet/SSH（远程登录）
  • 传输层：TCP（可靠传输）、UDP（高效传输）
  • 网络层：IP（地址寻址）、ICMP（网络诊断）、ARP（地址解析）
  • 网络接口层：Ethernet（以太网）、PPP（点对点协议）

二、操作步骤

  1. 理论梳理：默写 TCP/IP 四层模型层级顺序，标注每层核心作用，梳理每层对应常见协议，理清协议归属层级。

  2. 数据传输流程实操：模拟数据发送 / 接收过程，理解封装（上层数据向下层添加头部）、解封装（下层数据向上层剥离头部）流程。

  3. 协议验证实操：

    • 打开命令提示符，输入ping www.baidu.com，验证网络层 ICMP 协议、IP 协议工作流程；
    • 打开浏览器访问网页，验证应用层 HTTP/HTTPS 协议、传输层 TCP 协议联动机制；
    • 使用 Wireshark 工具抓取网络数据包，对应查看四层模型各层数据结构。

  4. 分层对比：区分 TCP/IP 四层与 OSI 七层模型的差异，明确安服工作中重点关注的应用层、传输层协议。

三、图片说明

  1. 以 TCP/IP 四层模型为核心框架，图中清晰对比了 OSI 七层、TCP/IP 四层与五层协议体系结构。其中，TCP/IP 四层模型各层分工明确，具体如下：

    • 应用层：为各类应用程序提供网络服务，定义通信规则，常见协议包括 HTTP/HTTPS、DNS、FTP、SSH 等。
    • 传输层：负责端到端的数据传输控制，建立主机间通信通道，通过 TCP 实现可靠传输、UDP 实现高效传输。
    • 网络层（网际层）：负责数据的路由寻址与跨网络转发，核心协议为 IP，并通过 ICMP、ARP 辅助实现网络诊断与地址解析。
    • 网络接口层：负责数据帧的封装、传输与接收，对接物理硬件，常见协议包括 Ethernet、PPP 等。

应用层：HTTP 协议数据，包含 GET / HTTP/1.1 请求，为用户提供网页访问服务。

四、修复 / 防御

  1. 基础防护：熟悉各层协议特性，避免因协议理解不足导致安全误判，比如区分 TCP 可靠传输、UDP 无连接传输的安全风险差异；
  2. 协议风险防范：针对应用层常见协议漏洞，提前梳理风险点；
  3. 网络排查：利用各层协议特性，快速定位网络通信故障，为后续安全排查、漏洞分析奠定基础。
