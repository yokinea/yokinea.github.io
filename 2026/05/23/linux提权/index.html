Linux系统提权

在渗透测试过程中，我们经常先拿到普通用户权限的 Shell，但普通用户权限太低，无法查看敏感文件、无法操作系统配置、无法持久化控制主机。

Linux 提权的核心目标：从普通用户权限，升级到 root 最高权限。

本篇文章记录 Linux 最常用、最基础、实战成功率最高的提权方式，适合新手学习、复盘、写作业。

一、提权原理概述

Linux 系统权限等级严格：

  • root：最高权限，拥有系统所有操作权限
  • 普通用户：权限受限，无法修改系统关键文件、无法查看 shadow 密码文件

提权本质就是：利用系统配置漏洞、权限配置不当、内核漏洞、特殊程序权限，突破普通用户限制，获取 root 权限。

二、提权前期信息收集

拿到 Linux 低权限 Shell 后，先收集系统信息，判断可以用哪种方式提权。

1. 查看当前用户权限

2. 查看系统版本、内核版本

内核版本过旧，大概率存在内核提权漏洞。

3. 查看可执行 sudo 权限

重点！如果这里出现 (root) NOPASSWD，大概率可以直接提权。

4. 查看定时任务

定时任务调用了用户可修改的文件，即可覆盖脚本获取root权限。

三、四种最常用的 Linux 提权方式

1. Sudo 权限配置不当提权

场景：管理员给普通用户分配了部分命令 sudo 免密执行。

很多自带命令（find、vim、bash、less）都可以逃逸root。

示例：如果 sudo -l 看到 find 可免密执行

直接拿到 root 权限！

同理：vim、less、more 都有对应的逃逸方式。

2. 内核漏洞提权（老系统多）

老旧 Linux 内核存在公开提权漏洞，例如 DirtyCow 脏牛漏洞。

原理：内核内存写入漏洞，低权限用户可篡改权限，提升为root。

利用方式：

  • 根据内核版本搜索对应 EXP
  • 上传编译脚本、执行提权
  • 直接获取 root shell

3. 定时任务 Crontab 提权

场景：root 定时执行某个脚本，普通用户拥有该脚本的修改权限。

利用思路：

  1. 覆盖原有脚本
  2. 写入反弹 Shell 或 添加后门账号
  3. 等待定时任务执行，即可获取 root 权限

4. 敏感文件权限泄漏提权

可以直接爆破密码、替换 root 密码，完成提权。

四、DC-1 靶场提权回顾

DC-1 靶场的就是find 命令 sudo 提权：

  1. 拿到普通 shell
  2. sudo -l 查看发现 find 免密
  3. 执行 sudo find 逃逸命令
  4. 成功拿到 root 最高权限

五、提权总结与防御方案

提权总结

  • 提权核心：找配置错误、找漏洞、找权限泄漏
  • 实战优先级：sudo权限滥用 > 定时任务 > 内核漏洞 > 敏感文件泄露

防御建议

  • 严格配置 sudo 权限，禁止普通用户拥有高风险命令权限
  • 及时更新系统内核，修复老旧漏洞
  • 定时任务脚本权限严格控制，禁止普通用户写入
  • 禁止普通用户读取 /etc/shadow、/etc/sudoers 等敏感文件
