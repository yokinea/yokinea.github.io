Linux文件系统与目录结构

前面我们完整掌握了计算机网络全套基础，本篇开始进入Linux运维基础系列。Linux 是服务器、后端、运维、安全岗位的必备系统，而文件系统和目录结构是 Linux 的核心根基，所有操作、权限、日志、进程都依托目录结构运行。

一、Linux 文件系统概述

Linux 系统的核心设计思想：一切皆文件。

无论是硬件设备、进程、网络接口、日志、配置，在 Linux 中全部以文件形式存在。目录也是一种特殊文件，用于存放和管理其他文件。

Linux 默认主流文件系统：ext4，特点是稳定、日志记录、容错性强，是服务器标准文件系统。

二、Linux 目录核心特点

  • 树形结构：唯一根目录，从根向下逐级分支，无盘符概念（和 Windows 最大区别）
  • 根目录标识 /：所有文件的最顶层入口，所有目录、文件都挂载在根目录下
  • 区分大小写：Linux 严格区分文件、目录大小写，test 和 Test 是两个不同文件
  • 隐藏文件：以 . 开头的文件/目录为隐藏文件，默认不显示

三、Linux 核心目录详解

Linux 所有系统目录功能固定、规范统一，面试、运维、排查问题高频考察。

目录路径 核心作用 实战场景
/ 系统根目录，所有文件的顶层入口 整个文件系统的起始节点
/root 超级管理员 root 用户家目录 root 登录默认所在目录，权限最高
/home 普通用户家目录集合 新建普通用户会自动生成 /home/用户名 目录
/etc 系统核心配置文件目录 环境配置、用户配置、服务配置、网络配置全部在此
/bin 普通用户可执行基础命令 ls、cd、cp、mv 等常用基础指令
/sbin 管理员权限系统命令 关机、重启、网络配置、系统修复等高权限指令
/usr 系统软件、程序、文档安装目录 安装第三方软件、源码程序、系统资源
/var 动态可变数据目录 日志文件、缓存、运行数据、数据库数据存放
/tmp 系统临时文件目录 存放临时文件、缓存文件，重启自动清空
/dev 硬件设备文件目录 磁盘、光驱、U盘、外设设备全部映射为文件
/proc 系统进程虚拟目录（内存映射） 实时查看进程、CPU、内存运行状态，无真实磁盘占用

四、绝对路径与相对路径

1. 绝对路径

从根目录 / 开始的完整路径，唯一、不会出错，适配所有场景。

示例：/etc/profile、/home/test/user.txt

2. 相对路径

相对于当前所在目录的路径，不以 / 开头，简洁高效。

常用符号：. 当前目录、.. 上一级目录

五、Linux 与 Windows 目录核心区别

  • Windows：多盘符结构（C/D/E盘），目录层级独立
  • Linux：单一根树结构，无盘符，全部挂载在 / 下
  • Windows 默认不区分大小写，Linux 严格区分大小写
  • Linux 隐藏文件靠 . 前缀，Windows 靠文件属性设置

六、总结

  1. Linux 核心思想：一切皆文件，目录、设备、进程均为文件。

  2. 根目录 / 是所有文件的入口，目录结构统一规范，固定不变。

  3. /etc 存配置、/var 存日志、/home 存用户、/tmp 存临时文件，是日常操作最高频目录。

  4. 绝对路径精准稳定，相对路径简洁高效，工作中按需使用。
