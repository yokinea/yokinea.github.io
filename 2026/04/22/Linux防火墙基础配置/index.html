Linux防火墙基础配置

上一篇我们掌握了Linux日志排查与分析技能，本篇讲解服务器安全核心基础：Linux防火墙配置。服务端口监听正常、程序无报错，但外网无法访问、存在恶意扫描攻击，基本都是防火墙策略导致。防火墙是服务器第一道安全屏障，也是部署上线、安全运维、面试必背知识点。

一、Linux防火墙核心介绍

CentOS 7+ 系统默认使用 firewalld 动态防火墙，替代了旧版 iptables。

核心作用：过滤进出服务器的网络流量，通过放行/拒绝端口、IP、服务，实现访问权限管控，阻挡恶意访问、端口扫描、非法连接。

核心优势：支持动态更新规则，无需重启服务，规则实时生效，适配生产环境动态配置。

二、防火墙基础状态管理

所有防火墙操作前提：掌握开启、关闭、状态查看、开机自启配置。

命令 核心作用 实战场景
systemctl status firewalld 查看防火墙运行状态 确认防火墙开启/关闭，排查端口不通根源
systemctl start firewalld 开启防火墙 服务器上线前开启，保障基础安全
systemctl stop firewalld 关闭防火墙 本地测试、内网调试临时关闭，生产环境禁止长期关闭
systemctl enable firewalld 设置防火墙开机自启 生产环境标配，防止重启后防火墙失效
systemctl disable firewalld 取消开机自启 测试环境临时配置使用

三、核心端口放行配置）

服务部署后外网无法访问，90%是端口未放行，掌握永久放行、临时放行、删除端口规则。

1. 永久放行端口

语法：firewall-cmd --permanent --add-port=端口号/协议

实战示例：

  • firewall-cmd --permanent --add-port=8080/tcp 放行8080端口
  • firewall-cmd --permanent --add-port=3306/tcp 放行MySQL端口（内网慎用）

2. 临时放行端口（重启失效）

不带 –permanent 参数，临时生效，重启防火墙/服务器后规则清空，适合临时调试。

3. 删除放行端口

语法：firewall-cmd --permanent --remove-port=端口号/协议

用于关闭无用端口，缩小服务器暴露面，提升安全等级。

4. 重载防火墙规则

所有带永久参数的配置，必须重载才能生效：firewall-cmd --reload

四、服务级放行配置

firewalld 支持直接放行预设服务，无需记忆对应端口，简洁高效。

  • firewall-cmd --permanent --add-service=http 放行80网页服务
  • firewall-cmd --permanent --add-service=https 放行443加密网页服务
  • firewall-cmd --permanent --add-service=ssh 放行22远程连接服务

五、规则查看与校验命令

配置完防火墙后，必须校验规则是否生效，避免配置不生效导致服务无法访问。

  • firewall-cmd --list-all 查看所有已放行端口、服务、防火墙完整规则
  • firewall-cmd --list-ports 只查看放行端口
  • firewall-cmd --list-services 只查看放行服务

六、IP访问控制

生产环境安全加固核心：禁止全网访问核心端口，仅放行指定IP。

1. 允许指定IP访问所有服务

2. 仅允许指定IP访问指定端口

常用于MySQL、Redis等核心服务，仅允许业务服务器IP连接，杜绝公网访问。

3. 拉黑禁止IP

针对恶意扫描、暴力破解IP，直接封禁拦截：

七、实战标准部署流程

服务器项目上线防火墙标准配置步骤：

  1. 开启防火墙并设置开机自启
  2. 放行业务所需端口/服务（80、443、自定义项目端口）
  3. 核心数据库端口仅放行内网业务IP
  4. 重载防火墙规则使配置生效
  5. 查看规则列表校验配置正确性

八、重点事项

1. 端口监听正常但外网访问不通？

优先排查两点：①Linux防火墙未放行端口 ②云服务器安全组未开放端口，本地监听正常仅代表服务正常，外网访问需双层放行。

2. –permanent 参数作用？

代表永久生效，不带则临时生效，重启失效；永久配置必须执行 reload 重载才能生效。

3. 生产环境防火墙配置原则？

最小权限原则：只放行必要端口，关闭所有多余端口，核心服务限制IP访问，减少攻击面。

九、总结

  1. firewalld 是CentOS7+默认防火墙，动态配置、无需重启服务。

  2. 日常核心操作：放行端口、删除端口、查看规则、重载配置。

  3. 外网访问不通优先排查防火墙与安全组放行规则。

  4. 生产严格遵循最小权限原则，禁止全开端口，做好IP白名单限制。
