Linux常用文件操作命令

上一篇我们掌握了Linux文件系统与目录结构，本篇继续进阶Linux核心基础——文件操作命令。文件操作是Linux最基础、最高频的操作，日常运维、项目部署、日志排查、面试提问都会涉及，本文汇总所有必用命令，极简干货、零基础可直接上手。

一、目录切换与查看命令

所有Linux操作的基础，用于定位、切换、查看目录位置与文件信息。

命令 核心作用 常用参数 & 实战用法
pwd 查看当前所在目录的绝对路径 无参数，直接使用，快速确认当前工作目录
cd 切换工作目录 cd .. 回到上一级目录；cd ~ 回到用户家目录；cd / 回到根目录
ls 列出目录下所有文件与目录 ls -l 详细信息展示；ls -a 显示隐藏文件；ls -lh 人性化展示文件大小

二、目录创建与删除命令

用于新建、移除文件夹，是项目部署、文件整理的常用命令。

命令 核心作用 实战用法
mkdir 创建空目录 mkdir test 创建单级目录；mkdir -p a/b/c 递归创建多级目录（核心参数-p）
rmdir 删除空目录 仅能删除空白文件夹，无法删除带文件的目录，日常使用较少
rm 删除文件/目录（核心删除命令） rm 文件名 删除文件；rm -r 目录 递归删除目录；rm -rf 目录 强制删除（无提示）

高危注意：rm -rf / 禁止执行！会强制清空系统所有文件，直接导致系统崩溃，无法恢复。

三、文件创建、移动、复制命令

文件日常管理核心四命令，覆盖90%的文件操作场景。

命令 核心作用 实战场景
touch 创建空文件、更新文件时间戳 touch test.txt 快速创建空白文本文件
cp 复制文件/目录 cp a.txt b.txt 复制文件；cp -r 目录1 目录2 复制整个文件夹
mv 移动文件、重命名文件 同目录=重命名，跨目录=移动文件，日常文件整理高频使用

四、文件内容查看命令

排查日志、查看配置、读取文件内容必备，不同命令适配不同场景。

命令 核心作用 适用场景
cat 一次性读取全部文件内容 适合查看小文件、配置文件，不适合大日志文件
less 分页查看文件内容，可上下翻页 查看中大文件，操作灵活，退出按 q
head 查看文件头部内容 head -n 10 查看前10行内容
tail 查看文件尾部内容 tail -n 10 查看末尾10行；tail -f 实时监控文件更新（日志排查神器）

五、文件查找与检索命令

服务器文件过多时，用于精准查找文件、检索内容，面试高频考点。

1. find 命令（精准查找文件）

全局搜索文件，根据文件名、大小、时间精准匹配。

常用：find / -name "*.txt" 从根目录查找所有txt文件

2. grep 命令（检索文件内容）

文本过滤工具，用于筛选关键字内容，日志排查核心命令。

常用：grep "error" log.txt 筛选日志中所有报错信息

六、总结

  1. 目录操作核心：cd、pwd、ls、mkdir -p，熟练掌握路径切换与多级目录创建。

  2. 文件操作核心：touch、cp、mv、rm -rf，重点注意rm删除命令的高危风险。

  3. 文件查看：小文件用cat、大文件用less、看头部用head、实时日志用tail -f。

  4. 检索排查：find找文件、grep筛内容，是运维排查问题的组合神器。
