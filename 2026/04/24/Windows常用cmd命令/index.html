Windows常用cmd命令

前面我们完整通关了全套Linux运维基础，从文件、权限、进程、网络到安全基线全部掌握。本篇正式进入Windows基础系列，优先讲解面试、渗透测试、日常排查最高频的 CMD 命令。Windows 服务器运维、靶场测试、内网渗透、故障排查，都离不开 CMD 基础指令，是网安、运维岗位必掌握基础技能。

一、CMD 基础介绍

CMD（命令提示符）是 Windows 系统自带的命令行交互工具，功能等同于 Linux 的终端。

核心作用：通过指令操作系统、查询系统信息、排查网络故障、管理用户权限、执行程序、批量处理文件。

打开方式：Win+R 输入 cmd 回车即可打开命令行窗口。

二、目录与文件操作命令

对应 Linux 中 ls、cd、mkdir、rm 等命令，用于 Windows 文件、目录管理。

CMD命令 核心作用 实战用法
dir 查看当前目录所有文件/文件夹 等同于 Linux ls，展示文件名称、大小、修改时间
cd 切换工作目录 cd .. 返回上一级；cd \ 返回根目录
md/mkdir 创建新文件夹 md test 快速创建 test 文件夹
rd/rmdir 删除文件夹 rd /s /q 文件夹 强制递归删除目录（无提示）
del 删除文件 仅删除文件，不能删除文件夹，常用于清理日志、垃圾文件
copy 复制文件 单文件复制，用于迁移配置、脚本文件
move 移动/重命名文件 同目录为重命名，跨目录为移动，用法同 Linux mv

三、系统信息查看命令

快速查询系统版本、配置、开机时间、系统架构，运维排查、信息收集必备。

  • systeminfo：查看系统详细信息（版本、补丁、开机时间、内存、网卡信息），信息收集核心命令
  • ver：快速查看 Windows 系统版本
  • hostname：查看本机计算机名
  • tasklist：查看系统所有进程列表（等同于 Linux ps）
  • taskkill：结束进程，taskkill /f /im 进程名.exe 强制杀死进程

四、网络操作命令

Windows 网络排查、IP 查看、连通性测试、DNS 解析核心指令。

命令 作用 实战场景
ipconfig 查看本机IP、子网掩码、网关、DNS 排查本机网络配置、IP地址、网卡状态
ipconfig /all 查看完整网络信息 展示MAC地址、DHCP状态、DNS服务器、网卡详情
ping 测试网络连通性、延迟丢包 排查外网、内网主机是否存活
tracert 路由追踪 定位网络卡顿、丢包节点，等同于 Linux traceroute
nslookup 域名解析测试 排查 DNS 解析异常、域名劫持问题

五、用户与权限管理命令

Windows 用户查看、账号创建、权限配置、后门账号排查高频命令。

  • net user：查看系统所有本地用户
  • net user 用户名 密码：修改用户密码
  • net user 用户名 /active:yes/no：启用/禁用用户
  • net localgroup administrators：查看本机管理员组所有用户（排查提权、后门账号核心）
  • net localgroup administrators 用户名 /add：将用户加入管理员组（提权操作）

六、端口与连接查看命令

排查端口占用、内网连接、异常外联、木马后门连接。

  • netstat -ano：查看所有TCP/UDP连接、监听端口、对应进程PID（Windows 排查端口神器）
  • netstat -an：查看所有网络连接状态，排查异常对外连接

七、日志与系统操作命令

快速打开系统工具、排查日志、系统配置。

  • eventvwr：打开系统日志查看器（安全日志、系统日志、应用日志）
  • services.msc：打开系统服务列表，管理服务启停、自启
  • taskmgr：快速打开任务管理器
  • regedit：打开注册表编辑器
  • shutdown /s /t 0：立即关机
  • shutdown /r /t 0：立即重启

八、CMD 实用组合技巧

1. 管道筛选

CMD 同样支持管道**|** 筛选内容，精准过滤信息：

tasklist | findstr java 筛选 Java 进程

netstat -ano | findstr 8080 筛选指定端口连接

2. 清屏与退出

cls：清空命令行屏幕

exit：退出 CMD 窗口

九、重点事项

1. 如何查看 Windows 所有端口占用？

使用 netstat -ano，可查看所有监听端口、建立连接、进程PID，精准定位端口占用程序。

2. 如何排查服务器后门账号？

通过 net user 查看所有用户，再通过 net localgroup administrators 查看异常管理员账号，排查非法提权后门。

3. 进程卡死如何强制结束？

先用 tasklist 找到进程名/PID，再使用 taskkill /f /im 进程名.exe 强制终止进程。

十、总结

  1. 文件目录操作：dir、cd、md、rd、del、move，适配日常文件管理。

  2. 系统信息：systeminfo、tasklist、taskkill，快速排查系统与进程异常。

  3. 网络排查：ipconfig、ping、tracert、netstat，解决90%网络与端口问题。

  4. 用户安全：net user 系列命令，是 Windows 账号安全、后门排查核心。

  5. 熟练管道筛选 findstr，可高效筛选日志、进程、端口信息。
