Linux系统安全基线基础

上一篇我们掌握了Linux防火墙防护策略，本篇进阶讲解服务器安全核心——Linux系统安全基线。安全基线是服务器必须满足的最低安全标准，是企业等保测评、服务器加固、渗透防护、面试必考核心内容。基线加固可以有效杜绝暴力破解、权限泄露、恶意入侵、配置漏洞等绝大多数基础安全风险。

一、安全基线核心概念

安全基线：系统、服务、账号、权限、日志、网络的最低安全配置标准，是所有服务器上线前必须完成的加固操作。

核心目标：缩小攻击面、最小权限管控、全程日志留痕、杜绝弱漏洞，保障服务器基础安全，满足企业安全规范与等保要求。

适用场景：新服务器上线加固、安全巡检、漏洞整改、等保测评、渗透测试修复。

二、账号安全基线加固

服务器入侵80%源于账号密码漏洞，账号安全是基线加固的第一优先级。

1. 禁用root远程登录

root权限过高，远程直接登录极易被暴力破解，生产环境必须禁止。

配置文件：/etc/ssh/sshd_config

修改参数：PermitRootLogin no

加固效果：攻击者无法通过root账号远程连接服务器，大幅降低爆破风险。

2. 密码复杂度策略

杜绝弱密码（123456、root、admin等），强制开启密码复杂度规则。

加固规则：密码长度≥8位，包含大小写字母、数字、特殊符号，定期更换密码。

配置路径：/etc/pam.d/system-auth

3. 闲置账号清理

定期检查系统无用账号、临时账号、过期账号，及时删除或锁定，避免账号遗留漏洞。

查看所有系统用户：cat /etc/passwd

锁定异常账号：usermod -L 用户名

4. 禁止空密码登录

关闭系统空密码登录权限，杜绝无密码账号直接登录服务器。

配置参数：PermitEmptyPasswords no

三、SSH服务安全加固

SSH是远程连接唯一入口，也是攻击扫描高频目标，需针对性加固。

  • 修改默认22端口：将SSH默认22端口改为高位端口（10000-65535），规避批量端口扫描与暴力破解
  • 限制登录重试次数：设置密码错误锁定机制，多次输错密码自动锁定账号，防止暴力破解
  • 关闭DNS反向解析：关闭SSH DNS解析，提升远程连接速度，避免解析漏洞
  • 启用密钥登录：优先使用SSH密钥登录，关闭密码登录，从根源杜绝密码爆破

四、文件权限安全基线

核心配置文件权限泛滥是常见高危漏洞，严格遵循最小权限原则。

1. 关键文件权限加固

  • /etc/passwd 权限设置644，仅允许管理员查看修改
  • /etc/shadow 权限设置000，禁止普通用户查看密码哈希
  • /etc/group 权限设置644，严控用户组信息访问权限
  • 系统配置文件禁止赋予777权限，杜绝任意用户篡改核心配置

2. 禁止目录写入执行权限泛滥

网站目录、业务目录禁止随意赋予777权限，防止上传恶意脚本、木马文件，避免文件包含、代码执行漏洞。

五、日志安全基线

日志是安全溯源、入侵排查、等保测评的核心依据，必须保证完整留存。

  • 开启系统日志审计：保证登录日志、操作日志、服务日志正常记录
  • 日志留存时长：企业等保要求日志留存≥6个月，支持入侵溯源
  • 禁止清空系统日志：禁止随意删除/篡改安全日志，防止入侵痕迹被抹除
  • 定期备份日志：防止日志丢失、日志被恶意覆盖

核心日志路径：/var/log/secure（登录安全日志）、/var/log/messages（系统日志）

六、端口与服务安全基线

关闭无用服务、收缩端口暴露面，是最简单高效的安全加固方式。

1. 关闭开机自启无用服务

关闭Telnet、FTP、rpcbind等非必要高危服务，减少攻击入口。

2. 清理多余监听端口

通过 netstat -tulpn 查看所有监听端口，关闭未使用端口，避免端口暴露漏洞。

3. 防火墙最小放行

仅放行业务必需端口，核心端口配置IP白名单，禁止全网开放数据库、Redis等敏感服务端口。

七、系统参数安全加固

通过修改内核参数，抵御网络攻击、DDOS、SYN洪水、ICMP攻击。

配置文件：/etc/sysctl.conf

  • 禁止ICMP重定向，防止路由劫持
  • 开启SYN洪水防护，抵御端口扫描、半连接攻击
  • 禁止IP源路由，防止伪造IP入侵
  • 关闭数据包转发，非路由服务器禁止转发流量

生效命令：sysctl -p

八、定时任务安全基线

定时任务是黑客植入后门、持久化控制的高频位置，需严格管控。

  • 定期查看定时任务：crontab -l
  • 禁止陌生定时任务、恶意脚本定时执行
  • 限制普通用户创建定时任务权限
  • 排查定时任务日志，发现异常及时清理

九、注意事项

1. 为什么要禁止root远程登录？

root是最高权限账号，默认账号公开，极易被暴力破解、端口扫描入侵。禁止远程登录后，攻击者无法直接爆破最高权限账号，大幅提升系统安全性。

2. 安全基线的核心原则是什么？

最小权限、最小暴露、全程留痕、定期巡检。只开放必要权限、必要端口，所有操作日志可溯源，定期排查漏洞。

3. 服务器常见高危漏洞有哪些？

弱密码、root远程可登、端口全开、核心文件权限过大、无用服务开启、定时任务后门、日志不留存。

4. 如何防止服务器暴力破解？

修改SSH默认端口、禁止root远程登录、开启密码复杂度、密钥登录、登录失败锁定、防火墙拉黑恶意IP多重防护。

十、总结

  1. 账号安全是重中之重，禁root远程、强密码策略、清闲置账号是基础操作。

  2. SSH加固、权限收紧、端口收缩，从入口减少攻击面。

  3. 日志完整留存、定时任务巡检，保障入侵可溯源、漏洞可排查。

  4. 内核参数加固抵御网络攻击，所有加固遵循最小权限安全原则。

  5. 安全基线不是可选配置，是生产服务器上线、等保测评的硬性标准。
