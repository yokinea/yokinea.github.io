常见网络端口与对应服务详解

前面我们吃透了 DNS 域名解析原理，想要完整掌握网络通信，必须搞懂IP 与端口的协作关系。IP 负责定位主机，端口负责定位服务。本文整理开发、运维、面试高频的端口知识，干货精简，快速掌握核心要点。

一、端口基础概念

端口是设备内应用程序的唯一出入口，是操作系统分配给网络服务的编号。

核心通信逻辑：IP 地址找到目标主机，端口号找到主机上对应的服务程序，二者缺一不可。

端口取值范围：0 ~ 65535，总共 65536 个端口。

二、端口分类标准

  • 公认端口（1-1023）：系统预留端口，绑定固定官方服务，普通程序无法随意占用
  • 注册端口（1024-49151）：开发者常用端口，可自定义部署项目、中间件服务
  • 动态端口（49152-65535）：客户端临时端口，用于主动发起网络请求，随机临时占用

三、高频常用端口对照表

整理日常开发、接口调试、服务器部署、面试最常用的端口，覆盖99%工作场景。

端口号 对应服务 实战作用说明
21 FTP 文件传输服务，用于服务器文件上传、下载、迁移
22 SSH 加密远程登录端口，日常服务器远程连接、操作服务器核心端口
23 Telnet 明文远程登录，无加密、安全性极差，现已基本淘汰
53 DNS 域名解析服务专属端口，UDP协议为主，负责域名转IP
80 HTTP 明文网页服务默认端口，浏览器访问时可省略端口号
443 HTTPS 加密安全网页服务默认端口，全网主流网站均使用此端口
3306 MySQL 关系型数据库默认端口，后端项目连接数据库核心端口
6379 Redis 内存缓存数据库端口，用于项目缓存、限流、会话存储
8080 自定义Web服务 Tomcat、SpringBoot 项目默认开发端口，最常用的自定义服务端口
27017 MongoDB 非关系型数据库默认端口，用于存储非结构化数据
1521 Oracle Oracle 数据库专属端口，企业级项目常用
8888 代理/调试服务 常用作本地代理端口、接口调试、抓包代理服务

四、开发常见端口问题

1. 端口占用问题

同一个端口同一时间只能被一个程序占用，启动项目提示端口占用，就是当前端口已被其他进程占用，需更换端口或杀死占用进程。

2. 端口放行问题

本地项目正常、外网无法访问，大概率是服务器防火墙未放行对应端口，需在安全组、防火墙中开启端口权限。

3. 默认端口省略规则

访问 HTTP 网站默认 80 端口、HTTPS 默认 443 端口，浏览器可自动补齐，地址栏无需手动输入端口号；其余自定义端口必须手动携带。

五、总结

  1. IP 定位主机，端口定位服务，二者配合完成网络通信。

  2. 熟知 80/443、22、3306、6379、8080 五大核心开发端口。

  3. 系统端口不可随意占用，自定义项目优先使用注册端口，避免冲突。

  4. 外网访问服务必须保证端口未占用、防火墙已放行。
