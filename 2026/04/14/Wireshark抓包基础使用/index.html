Wireshark抓包基础使用

前面我们掌握了DNS解析、网络端口基础知识，想要落地排查网络异常、看懂网络报文，必须掌握抓包工具。本文详解Wireshark基础原理、使用步骤、常用过滤指令、实战场景，是开发调试、网络排错的必备干货。

一、Wireshark 工具介绍

Wireshark 是一款开源、免费、跨平台的网络封包分析工具，也是目前行业主流的抓包软件。

核心作用：实时抓取本机所有进出的网络数据包，完整记录数据收发全过程，用于分析网络通信细节、定位网络问题。

二、核心使用流程

日常抓包固定五步流程，零基础可直接上手操作，适配所有网络排查场景。

  • 1. 选择网卡：打开软件，根据当前联网方式选择对应网卡（以太网/Wi-Fi），网卡选错将无法抓取数据包
  • 2. 启动抓包：双击选中网卡，软件开始实时抓取所有网络流量，页面持续刷新数据包
  • 3. 过滤流量：通过顶部过滤语法，筛选需要的指定协议、IP、端口数据，过滤无效冗余包
  • 4. 分析报文：选中数据包，逐层解析物理层、网络层、传输层、应用层数据，查看请求、响应、协议状态
  • 5. 停止并保存：排查完成后停止抓包，保存pcap格式文件，用于问题复盘、交接排查

三、高频过滤语法（工作必用）

Wireshark 抓包数据量大、杂乱，过滤语法是核心技能，以下为开发最常用指令。

过滤指令 作用说明 实战场景
http 只筛选HTTP协议数据包 调试接口、排查网页请求
https/tls 只筛选HTTPS加密数据包 排查加密请求、TLS握手异常
tcp 筛选所有TCP协议流量 排查三次握手、四次挥手、丢包重传
udp 筛选所有UDP协议流量 排查DNS解析、短视频、直播流量
ip.src == 192.168.1.100 筛选指定源IP的请求 只看本机发出的流量
ip.dst == 114.114.114.114 筛选指定目标IP的请求 排查访问固定服务器的流量
port == 8080 筛选指定端口流量 排查后端项目接口请求
tcp.flags.syn==1 筛选TCP握手请求包 分析TCP连接建立过程

四、数据包核心字段解读

  • Source（源地址）：请求发起方IP地址
  • Destination（目标地址）：请求接收方IP地址
  • Protocol（协议）：当前数据包使用的网络协议
  • Length（长度）：数据包大小
  • Info（信息）：数据包核心交互内容，展示握手、请求、响应状态

五、实战适用场景

Wireshark 是网络问题终极排查工具，可解决绝大多数疑难网络问题：

  • 排查接口请求超时、请求丢失、数据接收不全问题
  • 分析TCP丢包、重传、连接断开异常
  • 定位DNS解析失败、域名劫持问题
  • 排查跨域、请求拦截、数据篡改等网络异常
  • 学习网络协议，直观观察三次握手、四次挥手全过程

六、总结

  1. Wireshark 用于抓取、分析全网数据包，是网络排错核心工具。

  2. 抓包核心：选对网卡、精准过滤、分层分析报文。

  3. 可通过抓包直观验证TCP、DNS、HTTPS的协议工作流程。
